# Missing Person Detector and GPS Tracker

## 📌 Project Overview
This project aims to develop a system that combines facial recognition, GPS tracking and IoT technology to assist in locating missing persons.

## 🎯 Objectives
- Explore facial recognition for identification.
- Use GPS technology for location tracking.
- Integrate IoT communication for sharing location information.

## 🛠️ Technologies Used
- Raspberry Pi
- Python
- Facial Recognition
- GPS Module
- IoT Communication

## ⚙️ Working Principle
The system uses a camera and facial recognition to identify a person. GPS technology provides location information, which can be communicated through an IoT-based system.

## 🚀 Project Status
Successfully completed and tested as an academic project.

## 💡 Key Features
- Facial recognition using Raspberry Pi.
- GPS-based location tracking.
- Integration of facial recognition and GPS functionality.
- IoT-based communication.

## 🔒 Privacy Note
This repository does not contain personal facial images, private datasets or sensitive location information.
